# Internal docs

This folder holds the public docs for people who work on Rein. The site does not publish them.

- Put proposals, plans, open questions, design reasons and build status here.
- The site pages in `docs/` and `language/` describe Rein as it works today, for its users.
- An internal page can link to a site page. A site page does not link here.

## Pages

- [Decisions](decisions.md): why Rein works as it does, planned features, and the open questions.
- [Agent interface proposal](agent-interface.md): what comes next for the agent interface, and its open questions.
